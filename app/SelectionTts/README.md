# 剪贴板朗读（SelectionTts）

Windows 10/11 托盘小工具：**复制文本，自动朗读**，并在一个常驻的「朗读板」里显示当前内容、进度和剩余时间。  
用 Edge 在线语音（和 Edge「大声朗读」同一个引擎），无需登录、无需 API Key。

> 「划词朗读」和选区弹窗已经移除，现在只监听系统剪贴板。

## 一句话流程

```
复制 → 监听 → 存进朗读板（内存副本）→ 分块流式合成 → 边播边显示进度
                                                  ↘ 再复制 → 整段顶掉，从头开始
```

文本存进朗读板后就不再依赖剪贴板：之后谁清空、覆盖、锁定剪贴板都不影响这段朗读。

## 总开关

程序常驻托盘，但有一个**软件级总开关**（类似 VPN 的「连接 / 断开」）：

| 状态 | 表现 |
|---|---|
| 已启用 | 托盘图标彩色，菜单首项 `● 朗读已启用`，复制即读 |
| 已关闭 | 托盘图标**变灰**，菜单首项 `○ 朗读已关闭`，不监听、立即停止朗读、**朗读板清空** |

- 默认**关闭**，开关状态会被记住
- `Ctrl+Alt+R` 切换（可在设置里改）
- 关闭时板子不会消失，而是显示「已关闭 · 按 Ctrl+Alt+R 启用」，按钮变灰
- 关闭再打开**不会**补读关闭前那段内容（跟关闭期间复制的文本不补读是同一条规则）

## 朗读板

右下角的无边框浮窗（420×320，可拖动，位置会记住）：

```
┌────────────────────────────────────────┐
│ ● 正在合成 54%                          │
│   已合成 2100/5000 字                   │
├────────────────────────────────────────┤
│ ▓▓▓▓▓▓▓▓▓▓▓▓░░░░░░░░░░░░░░              │  ← 只表示合成进度
├────────────────────────────────────────┤
│ 第一行文字……                            │
│ 第二行文字……（正在读的这行整行淡绿）    │  ← 一行一个单元格
│ 第三行文字……                            │
├────────────────────────────────────────┤
│ ⏸ 暂停  ⏹ 停止                Ctrl+Alt+R 开关 │
└────────────────────────────────────────┘
```

- **不抢焦点**：复制时焦点仍留在原来的程序里，光标不跳
- **进度条只表示"引擎合成到哪了"**：分母永远是全文总字数；全部缓存好之后条子才收起
- **朗读到哪儿由高亮行表示**：高亮在哪一行，就是在读哪一行
- **正文按板子宽度自己折行，一行就是一个单元格**：鼠标移上去变手型，**点哪一行就从那一行的句子开头读**
- **已经合成过的句子不重新合成**：点已缓存的位置秒开（实测首个音节 2–5ms）
- **读到结尾就算读完**；如果中间有跳过没合成的句子，后台会静默补齐（不朗读），进度条补到 100%
- 第二行文字：合成中 `已合成 2100/5000 字`，朗读中 `剩余 02:31`，读完 `共 5000 字`，补合成阶段 `补合成 62%`
- 读完保留内容，不自动消失
- 点 `×` 只是隐藏；之后复制**不会**自动弹出，托盘菜单「显示朗读板」可以再打开

## 三个按钮的语义

| 按钮 | 作用 |
|---|---|
| `暂停` / `继续` | **临时**停止当前这段朗读，可从原处继续 |
| `停止` / `启动` | **软件总开关**（等同 `Ctrl+Alt+R`）：关掉会停止朗读并清空朗读板，按钮变成 `启动`，再点一下就回来 |

朗读板关掉后，板子上的 `启动` 和热键一样能重新打开，不需要记住快捷键。

## 托盘菜单

- `● 朗读已启用（点击关闭）` / `○ 朗读已关闭（点击启用）`（后面跟着当前热键）
- 显示朗读板
- 音色 / 语速
- 设置…
- 打开数据目录 / 打开日志
- 退出

> 旧版本的「停止朗读」已经删掉：停朗读请用板子上的 `暂停`，彻底停软件用首项的开关。

## 监听规则

| 情况 | 行为 |
|---|---|
| 普通文本 | 朗读 |
| 图片、文件列表（资源管理器里复制文件） | 忽略 |
| 密码管理器声明「不要被剪贴板工具处理」的内容 | 忽略 |
| 同一段文本 3 秒内重复复制 | 忽略（防手抖） |
| 连续快速复制多段 | 只朗读最后一次 |
| 剪贴板被别的程序临时占用（延迟渲染） | 最多再试 2 次（120ms / 300ms），同一次复制只念一次 |
| 超过 5000 字 | 只朗读前 5000 字 |

不修改、不还原你的剪贴板内容，不弹窗、不抢焦点。

## 设置（托盘 → 设置…）

### 引擎

| 引擎 | 说明 |
|---|---|
| **Edge**（默认） | 免费、无需配置。依赖网络，接口令牌算法会随版本变化 |
| **Azure** | 备用引擎。需要自己的订阅 Key，手动切换，不会自动降级 |

Azure 面板：

- `区域`：例如 `eastasia`、`eastus`
- `Key`：用 Windows DPAPI 加密后存进配置，**不存明文**；界面默认打码
- `测试合成`：立刻合一句，成功显示耗时，失败显示 401 / 429 这类明确原因

Edge 出问题时板子状态行会变红显示「朗读失败」，托盘也会弹提示——这时去设置里切到 Azure 即可。

### 快捷键

- 目前只有「开启/关闭朗读」可配，默认 `Ctrl+Alt+R`
- 点「录制」→ 按下组合键（必须带 Ctrl / Alt / Shift / Win 至少一个）
- 新组合被别的程序占用时**保持原热键不变**，并提示原因
- 改完立即生效，不用重启；托盘菜单和板子底部的提示会同步更新

热键是模块化的（`Platform/HotkeyActions.cs`），以后要加「停止朗读」「显示朗读板」只需加一行动作定义。

## 数据目录

优先使用 exe 旁边的 `data`（便携）；不可写时退回 `%LOCALAPPDATA%\SelectionTts`。

```
data\
  config.json     设置（不含朗读正文）
  logs\app.log    运行日志（只记字数，不记内容）
  cache\          自检缓存
```

`config.json`：

| 字段 | 说明 |
|---|---|
| `voice` | Edge/Azure 音色，例如 `zh-CN-XiaoxiaoNeural` |
| `rate` | 语速 `-20%` / `+0%` / `+20%` / `+50%` |
| `maxChars` | 单次朗读最大字数，默认 5000 |
| `engine` | `edge` 或 `azure` |
| `azureRegion` / `azureKeyProtected` | Azure 区域与 DPAPI 加密后的 Key |
| `hotkeys` | 动作 id → 组合键，例如 `{"toggle-watch":"Ctrl+Alt+R"}` |
| `watchEnabled` | 上次的总开关状态（默认 `false`） |
| `boardX` / `boardY` | 朗读板位置（-1 表示默认右下角） |
| `boardVisible` | 朗读板是否显示 |

## 命令行参数（调试用）

| 参数 | 作用 |
|---|---|
| `--watch` | 启动时强制打开总开关（不写入配置） |
| `--settings` | 启动后直接打开设置窗口 |
| `--selftest-drm` | 输出 Edge TTS 令牌，和 Python 版比对 |
| `--selftest-tts` | 合成并播放一段测试文本 |
| `--selftest-stream` | 验证流式合成、首包延迟、时间戳条数 |
| `--selftest-pipeline` | 验证分块流水线：首声、进度、抢占、停止 |
| `--selftest-config` | 验证 DPAPI、热键注册/换绑/回滚、配置往返 |

## 构建

需要 .NET SDK 10。

```powershell
cd app\SelectionTts
dotnet build -c Debug
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true `
  -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFile=true `
  -o publish\win-x64
```

发布产物是单文件，目标机器不需要安装 .NET。

## 已知限制

- Edge 引擎依赖网络；离线时无法朗读（可切 Azure，但 Azure 也需要网络）
- Edge 的令牌算法会随版本变化，升级时需同步 `Tts/DrmToken.cs`
- 合成单位是「一句话」：这样点行才能精确到句、已合成的不重做；代价是请求数比整段合成多（5000 字约 100+ 次请求），首次填满缓存大约需要一分钟——播放本身要十几分钟，所以始终跑在播放前面
- Azure 免费层有每分钟请求数限制，撞到 429 会自动等待并重试，表现为进度条暂时停住
- 单次最长 5000 字，超出部分截断
